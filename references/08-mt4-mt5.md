# 08 MT4／MT5 同步到斯巴達

給在 MT4 或 MT5 上交易（手動或用 EA）的策略方：在 MT4／MT5 掛一個同步程式 `OneBullExSync`，你在 MT 上的持倉會自動同步到 OneBullEx 斯巴達機器人帳戶。原本的交易方式不用改。

```
MT4／MT5（你的策略 EA 或手動下單）
   │ OneBullExSync 每秒讀取持倉（MT5 另外在每次成交時立刻讀取）
   │ 持倉有變化就送出；沒變化每 60 秒重送一次
   ▼
接收程式（跟 TradingView 共用同一套，見 03）
   │ 查實際持倉 → 補差額 → 確認成交
   ▼
OneBullEx 斯巴達機器人帳戶
```

- 同步程式**不會在 MT 上下單**，只讀取持倉。
- 送出的是**目標持倉**，所以重送不會重複下單；漏掉一次，下一次也會自動對齊。
- 只同步**已成交的持倉**。掛單成交後才同步；停損、停利在 MT 觸發平倉後，OneBullEx 也會跟著平倉。部分平倉也會同步。

## 能同步的商品

OneBullEx 必須有對應的合約。目前主要是：

| MT 商品（各券商名稱可能不同） | OneBullEx |
| --- | --- |
| XAUUSD、GOLD、XAUUSD.m… | `XAUSPARTANS_USDT` |
| BTCUSD | `BTCSPARTANS_USDT` |
| ETHUSD | `ETHSPARTANS_USDT` |

外匯貨幣對、指數、原油等，OneBullEx 沒有對應合約，不能同步。

## 需要準備

| 項目 | 說明 |
| --- | --- |
| 24 小時開著的 MT4／MT5 | 同步程式跑在 MT 終端機上，MT 關掉就不會同步。建議租一台 **Windows VPS**（固定 IP），MT 與策略 EA 都放在上面 |
| 接收程式主機 | 照 [02](02-server-setup.md)、[03](03-install.md) 安裝，取得 Webhook URL 與 passphrase。已經在用 TradingView 的可以共用同一台 |
| 同步程式 | 本倉庫的 `mt/OneBullExSync.mq4`（MT4）或 `mt/OneBullExSync.mq5`（MT5） |

## 1. 允許 MT 主機的 IP

接收程式預設只接受 TradingView 的 IP。要加入 Windows VPS 的對外 IP（在 VPS 的瀏覽器打開 https://checkip.amazonaws.com 查詢）：

```bash
sudo bash ~/onebullex-tradingview-bridge/bridge/install.sh set TV_ALLOWED_IPS tradingview,<VPS的IP>
```

`tradingview` 代表保留 TradingView 官方 IP；不用 TradingView 可以只填 VPS 的 IP。多台 VPS 用逗號分隔。

> 券商提供的 VPS 或 MQL5 虛擬主機，對外 IP 通常不固定，不適合用 IP 白名單。建議自己租固定 IP 的 Windows VPS。

## 2. 安裝同步程式

1. MT 選單「檔案 → 開啟資料資料夾（File → Open Data Folder）」。
2. 把 `OneBullExSync.mq4` 放進 `MQL4/Experts`（MT5 是把 `OneBullExSync.mq5` 放進 `MQL5/Experts`）。
3. 在 MT 按 F4 開啟 MetaEditor，開啟這個檔案，按 **F7 編譯**，下方應該顯示 `0 errors`。
4. 回到 MT，在「導航（Navigator）」的「EA 交易（Expert Advisors）」按右鍵重新整理，就會看到 `OneBullExSync`。

## 3. 允許連線到接收程式

MT 選單「工具 → 選項 → EA 交易（Tools → Options → Expert Advisors）」：

- 勾選 **允許 WebRequest 的網址（Allow WebRequest for listed URL）**
- 新增一行：你的主機網址，**只填到網域**，例如 `https://203-0-113-10.sslip.io`（不要加 `/webhook`）

沒有這一步，同步程式會顯示 `WebRequest error 4060`（MT4）或 `4014`（MT5）。

## 4. 掛上同步程式

把 `OneBullExSync` 拖到**任何一張**圖表上（只要掛一次，所有對應的商品都會同步），在「輸入參數」填：

| 參數 | 填什麼 |
| --- | --- |
| `WebhookURL` | 安裝時顯示的完整網址，例如 `https://203-0-113-10.sslip.io/webhook` |
| `Passphrase` | 安裝時顯示的 passphrase |
| `SymbolMap` | `MT商品=OneBullEx交易對`，多個用逗號分隔。商品名稱要和 MT「市場報價」顯示的**完全一樣**，例如 `XAUUSD.m=XAUSPARTANS_USDT` |
| `Multiplier` | 倍數，見下方「倉位大小」 |
| `HedgeMode` | `false` = 只同步淨部位；`true` = 多單、空單分開同步，見下方「鎖倉」 |
| `MagicFilter` | `-1` = 同步這個帳戶該商品的所有持倉；填數字 = 只同步該 magic number 的持倉（只想同步某一支 EA 時使用） |
| `PollSeconds` | 幾秒檢查一次，預設 1 |
| `ResendSeconds` | 持倉沒變時多久重送一次，預設 60；0 = 只在變化時送 |
| `LockAccount` | 只同步這個 MT 帳號；0 = 掛上時登入的帳號。換登入其他帳號時不會同步，避免誤同步 |

掛上後，圖表左上角會顯示每個商品的多、空數量和最後一次送出的時間或錯誤。

**掛上時會立刻同步目前的持倉。** MT 上已經有持倉的話，OneBullEx 會馬上開出對應的倉位。建議在 MT 空倉時掛上，或先在接收程式切換為試跑確認。

## 5. 先試跑

```bash
sudo bash ~/onebullex-tradingview-bridge/bridge/install.sh dryrun
sudo bash ~/onebullex-tradingview-bridge/bridge/install.sh logs
```

在 MT 開一筆最小手數，紀錄應出現：

```
收到訊號 XAUSPARTANS_USDT target=1.00000000 unit=coin
[試跑，不下單] XAUSPARTANS_USDT 目前 0 張 → 目標 ... 張：開多 ... 張
```

確認張數合理後 `install.sh live`，再用最小手數實際開、平一次，到 OneBullEx 核對持倉。

## 倉位大小

同步程式送出的是**實際數量**：手數 × 合約大小（例如黃金 1 手 = 100 盎司，以券商的合約規格為準）。接收程式再用 OneBullEx 的合約面值換成張數：

```
OneBullEx 張數 = MT 手數 × MT 合約大小 × Multiplier ÷ OneBullEx 每張面值
```

- `Multiplier = 1`：OneBullEx 的部位和 MT **一樣大**。黃金 0.01 手 = 1 盎司，名目價值約等於一盎司金價。
- 斯巴達帳戶資金比 MT 帳戶小，就按比例縮小。例如 MT 帳戶 10,000 美元、斯巴達帳戶 1,000 美元 → `Multiplier = 0.1`。
- OneBullEx 每張面值用 `python3 bridge/obx_tool.py spec XAUSPARTANS_USDT` 查。換算不足 1 張會捨去成 0（不下單）。
- 建議設定持倉上限防止倍數填錯：`sudo bash install.sh set TV_MAX_QTY <張數>`。

## 鎖倉（同時持有多空）

| HedgeMode | MT 多 1 手、空 1 手時 | 適合 |
| --- | --- | --- |
| `false`（淨部位） | OneBullEx 空手（淨部位 0） | 一般情況。盈虧和鎖倉相同，佔用保證金與手續費較少 |
| `true`（多空分開） | OneBullEx 也同時持有多、空各一份 | 希望 OneBullEx 帳面和 MT 完全一致，例如讓跟單者看到同樣的鎖倉 |

`HedgeMode = true` 需要斯巴達帳戶可以同時持有多空（合倉的雙向持倉）。兩邊都會佔用保證金，成交筆數也比較多。目前在 OneBullEx 正式環境實測過同時持有多空的是 BTCSPARTANS_USDT，黃金請先用最小數量驗證。

## 停止同步

- 移除同步程式**不會**平掉 OneBullEx 的持倉，只是之後不再同步。
- 要結束並平倉：先在 MT 平倉，確認 OneBullEx 也平倉了（紀錄出現 `完成`），再移除同步程式。
- 同步程式移除期間，在 MT 開平倉不會反映到 OneBullEx。重新掛上時，會一次對齊到 MT 當下的持倉。

## 注意

- **同一個交易對只用一個來源。** 同一個 OneBullEx 帳戶的同一個交易對，不要同時用 TradingView 警報或手動下單，持倉會互相覆蓋。也不要在 OneBullEx 手動平倉：重送時會被開回來。
- **價格與時間差。** OneBullEx 用自己的市價成交，跟 MT 的成交價會有差距，再加上約 1–2 秒延遲。剝頭皮等極短線策略，差距會比較明顯。
- **休市時間不同。** MT 的黃金週末休市。如果 OneBullEx 在 MT 休市期間仍有報價，持倉會照常受價格影響，而 MT 上無法調整。
- **MT 斷線。** MT 與券商斷線時，同步程式會暫停並在圖表顯示原因，恢復後自動對齊。

## 疑難排解

| 圖表左上角顯示 | 原因與處理 |
| --- | --- |
| `WebRequest error 4060`／`4014` | 步驟 3 沒有加入網址，或網址填錯（只填到網域） |
| `WebRequest error 5203`、`5200` 等 | 連不到主機。檢查網址、主機防火牆 443、接收程式是否在跑（`install.sh status`） |
| `HTTP 403` | VPS 的 IP 沒加入 `TV_ALLOWED_IPS`（步驟 1），或 VPS 的 IP 變了 |
| `HTTP 401` | Passphrase 填錯 |
| `HTTP 400 ...` | 交易對名稱錯誤或不在 `TV_SYMBOLS` 清單 |
| `symbol not found` | `SymbolMap` 的 MT 商品名稱和市場報價不一致（注意 `.m`、`.pro` 等後綴） |
| `not connected to broker` | MT 與券商斷線，恢復後會自動同步 |
| `is not the locked account` | 目前登入的帳號不是掛上時的帳號；重新掛上，或設定 `LockAccount` |
| 顯示 `sent` 但 OneBullEx 沒動 | 看接收程式紀錄（`install.sh logs`），例如試跑模式、換算不足 1 張、超過持倉上限 |
